# Metrô da Psicologia Social

App de estudo para o exame de Psicologia Social (NP1 + NP2), feito para o celular.

**Abrir:** https://annayt122.github.io/psicologia-social/

- 11 estações (uma por texto), com lições curtas e desafio de cada estação
- Quiz difícil, duelos e dissertativas com resposta-modelo
- Histórias da prova: casos com o conceito de cada trecho
- Cartões com repetição espaçada e resumão para a véspera

O progresso fica salvo no navegador de cada pessoa.
